The application ran a ColdFusion build whose upload handler could be coaxed into accepting a file type it was never meant to store, in a directory the server would then execute from. One unauthenticated POST to the filemanager endpoint was enough to turn a file upload into code running on the host.

Reported directly to the vendor's compliance team with the full request, a scored severity rating and the upgrade path that closes it. Fixed.

Authentication and session flaws chained end to end — from unauthenticated to holding someone else's account.

Privilege escalation

Roles that widen when they shouldn't, and boundaries between tenants, teams and admins that don't hold under pressure.

CWE-770 · Rate limiting & OTP

Expensive or sensitive operations with no ceiling — enumeration, brute force and one-time codes that aren't.

CWE-918 · SSRF

Servers persuaded to make requests on an attacker's behalf, reaching what the network trusts them to reach.

Protocol · Accounting desync

On-chain: the moment recorded value and realisable value diverge, and the path that makes the gap withdrawable.

05

How I work

Sensitive invariants

Before reading for bugs I write down what the system must never allow — balances that must reconcile, roles that must not widen, state that must not be reachable twice. A finding is then the shortest path to violating one of those statements.

Attack path modelling

A vulnerability is only worth anyone's time if there's a route from a realistic starting position to real damage. I model the whole path: entry, escalation, and the moment value or trust actually moves.

Reports people can act on

Reproduction steps, raw requests, PoC video, a severity I can defend against the vector, and a concrete fix. A report should let the engineer who owns that code start work without booking a call to ask me what I meant.
